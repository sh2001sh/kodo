# 自主委派优化：实现与分组实测

2026-10-20。P0/P1 已实现；P2 为探索性实验，不是统计显著性结论。

**协作操作缺口已补齐并经真实正控制验证；本轮仍未观察到自主委派，不能宣布自主协作已经优化成功，也不能把“提示不足”确认成唯一根因。**

## 已交付实现

- spawn_agent 明确省略卡片字段继承、显式字段只选已注册版本；错误给出修正方法，不静默回退。
- list_agents 移除裸 resultRef，提供结果可用性和状态。
- inspect_run 按受管运行／调用 ID 返回分页结果与文件、产物、进程证据；沿用持久审计恢复链授权，拒绝跨会话、同伴越权、伪造调用归属及无关产物。不返回模型请求、私有推理或工具原始参数。进程长输出恢复完整捕获后分页。
- 终态只有至多1200字符摘要；唤醒只有条件元数据。运行 completed、工具 succeeded、进程 exitCode 和宿主 quality 明确分开。
- 主角色独有的短分工方法：识别有收益的独立工作、提供资料包、推进不冲突工作、按需等待、核验证据，在新独立工作／范围增长／连续失败时重判。子代理继承卡片不会继承导演职责。

## 设计与限制

A=旧接口/旧方法，B=新接口/旧方法，C=旧接口/新方法，D=新/新；C不引用新接口才有的 inspect_run；Solo关闭协作工具并保留完整编程能力。三类任务各组2次，共30次，全部从干净工作目录和历史开始，组别按冻结顺序交错并在第二次反向；失败不替换。n=2/单元格仅作探索。

模型 CodeGo / deepseek-v4.1-flash / Chat Completions；实际返回标识：deepseek-v4.1-flash。1,000,000 token合并窗口，393,216最大输出；所有请求实际转发该输出上限：true。不设额外累计token、调用次数和短任务时长限制；数字计时器采用平台上限，子代理8、模型并发2。实际提示远小于模型窗口，本实验不验证满窗口保真。

任务为两个互不依赖模块、先定统一键契约再整合三个模块、单函数端口修复。这些小型代码夹具提供可分工机会，但未证明委派具有净收益；不能将“可拆分”视作“必须委派”。真实大型仓库的泛化尚未验证。模型看到同一规格，隐藏验收在工作目录外；process.exec仍是可信高权限执行，不能视作OS沙箱。

期间有本地检查并行及另一批工作目录改动，可能影响墙钟时间。五个运行版本均为预先复制的冻结目录，不随当前工作目录修改；13:13:59 UTC的354项回归属于该冻结实现。后续当前合并状态另行构建、类型检查和lint通过；完整回归以2个worker运行：20个文件、378项全部通过（21:39:40本地，51.89秒）。默认并行运行曾触发5秒测试超时，相关用例单跑通过；降低测试worker后未放宽超时、未跳过用例。当前合并状态包含其他工作的改动，不将冻结性能成绩冒充合并版成绩。

## 验收夹具修正（保留原始记录）

原始外部验收有两类超出规格的假设：get/has/size必须立即物理删除过期条目；非法TTL必须抛RangeError。规格只要求读不到过期值、size数活条目、sweep删除并计数、非法TTL被拒绝，未规定这些副作用／异常子类。另允许任务明确要求的新增 *.test.mjs 文件。修正后的外部验收统一复核所有同一批产物；没有重跑模型或修改原始成绩。正反控制覆盖按需清理和TypeError实现。

原始通过 24/30，按规格复核 27/30。被修正的误判：independent/A/2、independent/B/2、independent/C/1。真实失败：small/B/1、small/A/2、small/Solo/2；端口任务将全空白字符串当作默认端口，违反题目仅接受非空数字串的条件，自写测试通过但隐藏边界失败。运行结束不等于验收通过。

## 结果与消耗
